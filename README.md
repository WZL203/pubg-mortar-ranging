# 🎯 PUBG 迫击炮测距 💣

> 🍗 大吉大利，今晚吃鸡！标点距离一键测好，迫击炮指哪打哪。

队友在地图上标了点，还在拿尺子量距离？这个小工具帮你自动算：截取小地图 → 识别彩色标点 → 换算成米数 → 透明悬浮窗直接把距离显示在屏幕上 📏

## ⬇️ 下载使用（小白版）

1. 打开本仓库的 [Releases 页面](https://github.com/WZL203/pubg-mortar-ranging/releases)，下载 **PUBG.exe**（约 68 MB）
2. **双击 PUBG.exe 直接运行**，不用装 Python、不用配环境 ✅
3. 进游戏按 **N** 打开地图，队友标好点后按 **F1** ⚡
4. 四个标点的距离立刻以悬浮窗显示：🟡 黄 1 号、🟠 橙 2 号、🔵 蓝 3 号、🟢 绿 4 号，没标的显示「无标点」
5. 每次测距结果都会记进同目录的 `distance_log.txt` 📝

## 🧠 识别原理

- 纯**屏幕截图 + 图像识别**（mss 截图 + OpenCV），不读游戏内存、不注入进程、不模拟输入 👀
- 认的是地图上的水滴形标点：黄=1、橙=2、蓝=3、绿=4
- 抗轰炸区 🔥 三重锁定：**外圈颜色 + 内部黑底白字数字 + 底部水滴尖角**同时满足才算数，红区再红也不会把空地误报成标点
- 距离 = 标点尖端到地图中心的像素距离 ÷ 校准比例 × 100

## ⚠️ 使用须知

- exe 里的截图区域、地图中心和比例尺是按作者自己的显示器布局写死校准的，**换了分辨率或屏幕布局，距离可能不准**，这种情况请用下面的源码版自己改参数
- 本工具仅供学习交流，使用风险自担

## 🛠️ 源码运行（可自己校准）

```bash
pip install opencv-python numpy mss
python 1.py
```

改 `1.py` 开头几个写死参数即可适配自己的屏幕：

| 参数 | 含义 |
|---|---|
| `FIXED_REGION` | 小地图截图区域（左, 上, 宽, 高） |
| `CENTER_X / CENTER_Y` | 地图中心在截图内的像素坐标 |
| `DEFAULT_PX_PER_100M` | 比例尺：100 米对应的像素数（训练场实测校准） |
| `UI_BASE_X / UI_BASE_Y` | 结果悬浮窗显示位置 |
