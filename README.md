# PUBG 迫击炮测距

PUBG 迫击炮自动测距小工具：截取小地图区域，识别队友的彩色标点位置，按校准比例换算成米数，用透明悬浮窗把每个标点的距离直接显示在屏幕上。

## 原理

- 纯**屏幕截图 + 图像识别**：用 mss 截取小地图区域，OpenCV 在 HSV 色彩空间里找标点。
- 识别目标是地图上的水滴形标点（黄=1、橙=2、蓝=3、绿=4 号队友）。
- 抗轰炸区（红区）干扰用三重锁定：**外圈对应颜色 + 内部黑底白字数字 + 底部水滴尖角**同时满足才判定为标点，避免把红区空地误报成标点。
- 距离 = 标点尖端到地图中心的像素距离 ÷ 校准比例（px/100m）× 100。
- 不读游戏内存、不注入进程、不模拟输入，只看屏幕像素。

## 依赖

```bash
pip install opencv-python numpy mss
```

Windows 平台（用到 Win32 热键与窗口样式 API）。

## 使用

1. 先改 `1.py` 开头的写死配置，改成你自己的屏幕布局：
   - `FIXED_REGION`：小地图在屏幕上的截图区域（左， 上， 宽， 高）
   - `CENTER_X / CENTER_Y`：地图中心（自身位置）在截图内的像素坐标
   - `DEFAULT_PX_PER_100M`：比例尺，地图上 100 米对应的像素数（进训练场实测校准）
   - `UI_BASE_X / UI_BASE_Y`：结果悬浮窗的显示位置
2. 运行：

```bash
python 1.py
```

3. 游戏里按 **N** 打开地图，队友标好点后按 **F1**，四个标点的距离会以悬浮窗显示 3 秒，同时在地图原位画出识别框方便核对。
4. 每次测距结果会追加写入同目录的 `distance_log.txt`，主窗口点「查看日志」可打开。

## 说明

代码里的数值是作者自己显示器布局下标定的，换分辨率/屏幕位置必须重新校准上面几个参数，否则距离不准。
